# DATU Architects: web images

Compressed renders for the DATU Architects website, served through jsDelivr:

```
https://cdn.jsdelivr.net/gh/josephbrianmnl/DatuArchitectsAssets@v1/img/<drive-file-id>-<1200|2400>.jpg
```

Each file is named by the Google Drive file ID of its source render, so the site's `Images`
tab maps to it with no extra column. Sources are the PNG renders in the project's Drive
folder; these are JPEG re-encodes (2400px and 1200px wide).

Images are design-concept renders shown publicly on the site. Do not add anything here that
is not already public.
